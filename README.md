## 🚀 What I’ve Been Crafting

### 🔗 C.L.A.S.S – Cognitive Learning with AI for Skill & Success  
An AI-first platform redefining how students and professionals organize, learn, and grow — all in one space.  

🌐 [Visit the platform](https://class-teal.vercel.app/)

**Features & Stack:**  
- Built with **React, FastAPI, MongoDB, LangChain**, and **Gemini API**

📚 **Key Modules**:
- **Smart Dashboard** – Adaptive productivity insights and quick tool access  
- **Task Management** – Dynamic to-do system to organize goals and track progress  
- **AI-Powered Notes** – Enhanced note-taking with summaries, external content, images, and AI-suggested insights  
- **B.R.A.I.N** *(Boosting Resources for AI-driven Knowledge)*:  
  - **Summarizer** – Instant summaries from large documents  
  - **Mind Map Generator** *(Coming Soon)* – Visualize topic relationships  
  - **Flashcard Generator** – Auto-flashcards to retain key concepts  
- **SolveX** – Ask questions from PDFs, DOCs, and images  
- **OratoPrism** – Analyze and improve spoken English and communication style  
- **Resume Scorer** – AI-driven resume analysis and suggestions  
- **Community Forum** – Collaborate, discuss, and grow with a learning community

### 🧬 Medical Image Denoising & Generation using GANs  
A GAN-powered pipeline for improving and augmenting limited medical image datasets.  

**Features & Stack:**  
- Used **TensorFlow, Keras, OpenCV, NumPy**  
- GAN-based synthetic data generation for rare medical cases  
- Custom denoising model to enhance noisy, low-resolution scans  
- Boosted training data diversity for better diagnostic model performance  
- Ideal for radiology datasets with limited real-world samples

### 🧠 Gemma-Python – LLM Finetuned for Python QA  
Finetuned Google’s Gemma model to become a sharp, Python-focused coding assistant.  

**Features & Stack:**  
- Finetuned with **LoRA**, deployed using **Hugging Face Transformers**  
- Curated domain-specific Q&A datasets for Python  
- Real-time inference via streamlined API setup  
- Optimized for code reliability, syntax coverage, and beginner-to-advanced queries  

[![GitHub](https://img.shields.io/badge/GitHub-View%20Repo-black?logo=github)](https://github.com/prishasawhney/Gemma-Python-Programming)

### 🕹️ Skill Voyage – VR-Based Motor Skills Trainer for Kids  
A gamified VR experience that helps children develop fine and gross motor skills in an immersive environment.  

**Features & Stack:**  
- Developed using **OpenCV, MediaPipe**, and **custom 3D hand-tracking models**  
- Real-time hand movement replication with scaling based on depth  
- Interactive VR challenges designed to promote early motor development  
- Cost-effective and research-backed solution targeting accessibility in ed-tech
